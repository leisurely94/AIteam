## 三、从「能聊」到「能办事」的缺口

按投入产出排序，下一阶段优先补：

1. **工具执行器（白名单）**：取数、查日志、发消息、写日程，一个注册表 + 每个工具的参数校验。
2. **调度与巡检**：定时任务、到点复核、未完成自动提醒。
3. **知识检索**：把企业文档/历史消息检索结果作为可引用的上下文，答案标注来源。
4. **语音与形象扩展**：TTS 出声、口播视频，沿用现有 `voice` 字段与形象资源。

在此之前，本仓库的定位是**「会把活拆清楚、写明白、互相评审」的数字人团队**，不是全自动执行器——产出的是可交付的方案与文档，而不是替你去点系统。
